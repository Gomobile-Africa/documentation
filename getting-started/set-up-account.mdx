You can reach Gomobile by creating an account or accepting an invitation to an existing organization.

## Before you begin

Have access to:

- your work email;
- a password that meets the requirements shown on screen;
- a Moroccan mobile number you can verify during new-organization setup;
- your organization's name, if you are creating a new organization.

## Create a new account

<Steps>
  <Step title="Open Sign up">
    From the Gomobile sign-in page, choose **Sign up** and enter the requested account details.
  </Step>
  <Step title="Verify your email">
    Enter the six-digit verification code sent to your email address. If it does not arrive, check spam, confirm that you used the correct address, and use the resend action when it becomes available.
  </Step>
  <Step title="Name your organization">
    Enter the organization name that should identify your team in Gomobile.
  </Step>
  <Step title="Verify your phone">
    Enter your Moroccan mobile number and submit the one-time code sent to that number.
  </Step>
  <Step title="Continue to Gomobile">
    Follow the remaining onboarding choices and enter the workspace. The exact path can differ depending on whether you want to begin in the web application or with an API integration.
  </Step>
</Steps>

<Warning>
  Onboarding can offer to generate resources and request a real test call. Review the destination and available credits before confirming any test. The complete first-session path should be verified in your environment because available options depend on organization and channel configuration.
</Warning>

<Info>
  The phone field accepts Moroccan mobile numbers. Use the validation guidance shown under the field if your number is rejected.
</Info>

## Accept an invitation

<Steps>
  <Step title="Open the invitation link">
    Use the link in the invitation email. Invitation links identify the organization you are joining.
  </Step>
  <Step title="Complete account access">
    Sign in or complete the requested account steps with the invited email address.
  </Step>
  <Step title="Confirm the organization">
    After acceptance, verify that the expected organization appears in your account menu.
  </Step>
</Steps>

## Expected result

You arrive in the Gomobile workspace and can see the navigation allowed by your organization role.

## If setup does not complete

| Problem | What to try |
| --- | --- |
| Verification code is missing | Check spam, confirm the email address, wait briefly, and request another code when the option is shown |
| Phone number is rejected | Use a Moroccan mobile number and remove unsupported characters |
| One-time code does not work | Use the most recent code and request a replacement after it expires |
| Invitation does not open | Confirm you are using the invited email and request a new invitation from your organization administrator |
| You return to onboarding | Finish all required organization and phone-verification steps before opening the dashboard |
