The sidebar organizes work by customer task. Pages can remain visible even when your role cannot perform every action; Gomobile enforces permissions when you open a page or attempt an operation.

## Main navigation

| Area | Use it to |
| --- | --- |
| Campaigns | Create, schedule, launch, manage, and report on audience outreach |
| Inbound | Route available phone numbers to AI agents or Voice flows and review inbound results |
| WhatsApp | Review connection state and manage message templates |
| Contacts | Manage people, custom attributes, imports, and contact interactions |
| Audiences | Maintain static contact groups and rule-driven live segments |
| Agents | Configure AI voice agents and publish them for inbound calls |
| Flows | Build, test, and report on Voice and Multichannel automations |
| Knowledge bases | Manage documents that compatible AI agents can use |
| Dictionaries | Manage Arabic and French pronunciation audio entries |
| Audio | Upload, record, organize, and play reusable audio |
| Activity → Runs | Investigate individual flow executions |
| Activity → Calls | Investigate placed and answered calls |
| API keys | Create and manage API credentials for integrations |
| Settings | Configure organization calling hours and security |

<Note>
  **Messages** appears under Activity but is not available in the platform. It is intentionally not covered as a customer workflow.
</Note>

## Account menu

Use the account menu to confirm your signed-in identity and organization, switch the interface language, or log out. Organization and profile editing are not part of the current customer settings.

## Header status and actions

Eligible users can see the organization's available credit balance in the header. Some other header items are marked coming soon and are not documented as available features.

## A recommended order for a new workspace

<Steps>
  <Step title="Check calling hours">
    If your role allows it, open **Settings → Calling hours** and confirm when campaigns may place calls.
  </Step>
  <Step title="Prepare customer data">
    Open **Contacts** to create a contact, define any needed custom attributes, or import a list.
  </Step>
  <Step title="Create an audience">
    Decide whether membership should be manually controlled or maintained by rules.
  </Step>
  <Step title="Build and test a flow">
    Choose Voice or Multichannel, add a small number of steps, save, and test with safe data.
  </Step>
  <Step title="Launch a campaign">
    Connect the audience and flow, review the schedule and channel resources, then launch.
  </Step>
</Steps>
