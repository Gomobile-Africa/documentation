A knowledge base groups documents that a compatible AI agent can use as supporting information. Instructions define how the agent should behave; knowledge documents supply information about the subject.

For example, an appointment assistant’s instructions can tell it to answer preparation questions, while its knowledge base contains the reviewed preparation guide.

## Document readiness

Uploading a document starts processing. Upload success does not establish that the document is ready for use. Review its processing status and resolve failures before relying on it in an agent experience.

Keep documents accurate, relevant, and authorized for the intended audience. Test representative questions after documents are ready and attached through a supported agent configuration.

## Compatibility

Knowledge-base attachment depends on the agent’s pipeline. Realtime agents do not currently expose the Knowledge Base tab in the current UI. Do not assume every agent can use the same attachment workflow.
