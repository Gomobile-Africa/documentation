A campaign, run, and call describe different levels of activity. Start with the overall result, then inspect the execution or interaction that explains it.

| View or concept | What it explains |
| --- | --- |
| Campaign results | Enrolled contacts, tries, outcomes, progress, and applicable usage |
| Run | Steps and values for an individual flow execution |
| Call | One voice interaction, its timeline, outcome, and available media |
| Try | One campaign attempt to reach a contact |
| Outcome | The resulting contact or interaction status |
| Inbound report | Results for a phone number’s binding period |

## Activity and report updates

Activity marked **In progress** is still underway. Reports can update as calls, runs, and processing finish. Check the report's time range and latest update before interpreting the results.

## Recordings and transcripts

Call details can include recordings and transcripts when available. A recording may cover the full call or a specific recorded step. Availability depends on the call's configuration and processing.

For an appointment reminder, check campaign outcomes first, the contact’s run next, and call details if you need to investigate the voice interaction. Completion alone does not establish a business result such as payment or appointment attendance.
