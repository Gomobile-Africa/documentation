A credit is Gomobile’s prepaid usage unit. It is not a currency. Eligible users can see the organization’s balance, while calls, runs, and campaigns show applicable usage and cost breakdowns.

## Before a test or launch

Check the available balance alongside required phone numbers, sender IDs, and other channel resources. Flow tests, campaign activity, and AI-agent interactions can incur usage; a test is not a simulation.

## Balance versus pricing

A numeric balance does not establish a currency conversion or per-call price. Do not infer pricing, top-up, invoice, or retention commitments from activity results.

The documented balance API is read-only and requires an Admin API key. It does not add credits.
