If you think of an outreach operation as a **program**, the customer-facing Gomobile object is a **campaign**. The UI and API documentation use Campaign.

A campaign connects one audience to one saved flow, with scheduling, channel resources, calling hours, and eligible retries. The audience and flow binding cannot be replaced after creation.

For appointment reminders, the audience identifies recipients, the flow defines the reminder, and the campaign controls when the operation runs.
