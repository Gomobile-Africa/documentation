An audience groups contacts for a campaign.

| Type | Membership | Example |
| --- | --- | --- |
| Static | Manually added or removed contacts | A reviewed test list |
| Live | Contacts enter and leave as they match rules | Customers with an upcoming renewal |

The type cannot be changed after creation. A static campaign uses a launch membership snapshot. A running live campaign can enroll additional matching contacts.

An audience selects recipients; the flow defines their experience.
