## Before you begin

Define the qualification question and the contact fields or tags that will store the result.

<Steps>
  <Step title="Prepare the audience">
    [Create an audience](/quickstarts/create-audience) and review its membership and required contact data.
  </Step>
  <Step title="Configure the experience">
    Build a Voice flow with a short introduction, keypad input, and response branches. Update the contact or apply a tag on each supported path. Test each branch before campaign use.
  </Step>
  <Step title="Test the workflow">
    [Save and test the flow](/getting-started/build-first-flow) with contacts and numbers you control. Check each relevant branch and required value.
  </Step>
  <Step title="Review and launch">
    Follow [Launch your first campaign](/getting-started/launch-first-campaign). Check audience, flow, schedule, calling policy, and channel resources in the summary before launch.
  </Step>
</Steps>

## Expected result and verification

Check the run path and stored qualification result. Treat missing responses separately from a negative answer.

## Troubleshooting

If work does not begin, check campaign state, schedule, calling hours, audience eligibility, saved flow validity, resources, and credits. For an individual failure, inspect the run path and associated call activity.

See [campaign lifecycle](/product/campaign-lifecycle) for enrollment, retries, pause, and stop behavior.
