Find the API operations documented in this reference. Authenticate requests with `X-API-Key`; access depends on the key’s role and enabled services.

## Resource references

| Area | Documented operations | Reference |
| --- | --- | --- |
| Contacts | Contact CRUD/upsert/interactions, custom attributes, and ingestion | [Contacts API](/developers/reference/contacts) |
| Audiences | CRUD, membership, rules, and preview | [Audiences API](/developers/reference/audiences) |
| Flows | CRUD, run inputs, run/cancel, run report, and funnel | [Flows API](/developers/reference/flows) |
| Campaigns | Drafts, lifecycle, reports, contact results, and funnel | [Campaigns API](/developers/reference/campaigns) |
| Runs and calls | Organization runs, call request/list/detail, and exports | [Runs and Calls API](/developers/reference/runs-and-calls) |
| Inbound | Existing binding report and flow-binding funnel | [Inbound API](/developers/reference/inbound) |
| Agents | Options, CRUD, lifecycle, text test, and inbound publication | [Agents API](/developers/reference/agents) |
| Knowledge bases | CRUD, document upload/status/reprocess/delete | [Knowledge Bases API](/developers/reference/knowledge-bases) |
| WhatsApp | Channel status and template lifecycle | [WhatsApp API](/developers/reference/whatsapp) |
| Audio and dictionaries | Reusable WAV assets and pronunciation dictionaries | [Audio and Dictionaries API](/developers/reference/audio-and-dictionaries) |
| Credits | Admin-only balance read | [Credits API](/developers/reference/credits) |

See [API access and support](/developers/support-boundary) for connection requirements and help with integration needs not covered here.
